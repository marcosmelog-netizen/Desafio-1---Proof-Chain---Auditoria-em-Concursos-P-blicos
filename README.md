# Desafio-1---Proof-Chain---Auditoria-em-Concursos-P-blicos
Camada blockchain de auditoria híbrida, segurança criptográfica e transparência para concursos públicos. Utiliza SHA-256 local, mensageria assíncrona, backend em Flask e Smart Contracts em Solidity (Ethereum Sepolia) para garantir registros imutáveis e perfeitamente auditáveis em tempo real. Desenvolvido para o Hackathon HackWeb
